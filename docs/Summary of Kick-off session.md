Here is a full summary of the Tech Triathlon 2026 kick-off meeting:

### Meeting Overview

  * **Host & Organization**: Hosted by Chanuka, Associate Brand Marketer at Rootcode. Rootcode is an AI transformation company working with global enterprises and governments.
  * **Event Purpose**: Officially kicks off the Tech Triathlon 2026 competition, presenting the theme, phase timelines, rules, deliverables, and judging criteria.
  * **Participants**: Over 170 teams and 100+ participants from Sri Lankan universities.

-----

### Core Structure & Major Changes

  * **Theme**: *"The Intelligent Enterprise"* — focusing on connecting people, processes, and systems to enable faster, data-driven decisions.
  * **Integrated Format**: Unlike previous years with separate tracks, this year features **one continuous business challenge** that spans all three disciplines: Design, Engineering (Hackathon), and AI (Datathon).
  * **Prizes & Incentives**:
      * Cash Prizes: 500,000 LKR for 1st place, 200,000 LKR for runners-up, and 100,000 LKR for 2nd runners-up.
      * Additional benefits include fast-track internship pathways, spotlighting on Rootcode's website, certificates, and career guidance.

-----

### Phase Breakdown & Key Deliverables

#### 1\. Design Phase (Days 1–5)

  * **Lead**: Danushka (Associate Lead Designer at Rootcode).
  * **Core Concept**: "One Operation, One System" — creating an interconnected system for all personas.
  * **Key Requirements**:
      * Focus only on essential screens to accomplish core user jobs (restraint is evaluated).
      * Provide at least one **regression screen ("sad path")** demonstrating failure handling.
  * **Deliverables**:
      * Figma file containing User Personas, User Screen Flows, and Regression Screens on separate pages.
      * Interactive prototype link (Figma, Framer, or HTML).
      * 3–5 minute YouTube video explaining the interaction design.
      * AI Tool Disclosure. Optional items include style guides and code explanations.
  * **Scoring Weightage**: Problem Framing (25%), Visual & Interaction Design (50%), User Context Fidelity (20%), Restraint & Prioritization (50%), Regression Screen Quality (15%), Domain Accuracy (10%).

#### 2\. Hackathon Phase / Engineering (Days 6–10)

  * **Lead**: Krishan.
  * **Core Concept**: Developing a fully operable, end-to-end working product based on the design phase.
  * **Key Requirements**:
      * Mobile-responsive web application.
      * Minimal changes to the original design; any deviations must be documented in the repository.
      * Git commit history must be maintained (bulk/single commits at deadline are disallowed).
  * **Deliverables**:
      * Public deployed URL with seed user account credentials.
      * GitHub Monorepo containing a detailed `README`, a single `docker-compose` file (for running the app with seed data), and architecture/data-model diagrams under a `document/` folder.
      * 5–8 minute demo video explaining user flows and architecture.
      * AI Tool Disclosure document (`.md` file).

#### 3\. Datathon Phase / AI Intelligence Layer (Days 11–15)

  * **Lead**: Gajendra (Senior Data Scientist at Rootcode).
  * **Core Concept**: Building the intelligence layer using raw data to derive actionable insights aligned with business use cases.
  * **Key Restrictions**:
      * Pre-trained models are prohibited (except for basic pre-processing or data generation).
      * Proprietary API-based services, low-code, and no-code AI tools are prohibited.
  * **Deliverables**:
      * Architecture diagrams and data pre-processing documents.
      * Trained best-fit model submitted in `.h5` or `.pkl` format.
      * Jupyter Notebooks, including a designated "final notebook" (`TeamName_FinalNotebook.ipynb`) with printed cell outputs.
      * 3–5 minute YouTube demo video detailing approaches and decisions.
      * Zip folder submission containing all assets (`TeamName_Datathon.zip`).

-----

### Timeline & Deadlines

  * **Kick-off & Brief Release**: Challenge booklet released at midnight (12:00 AM Sri Lanka Standard Time).
  * **Day 5**: Design Phase Submission.
  * **Day 10**: Hackathon Phase Submission.
  * **Day 15 (October 9th)**: Datathon Phase Submission.
  * **Post-Phase**: Semi-finals (in-person presentations/Q\&A at Rootcode) followed by the Grand Finals.

-----

### General Competition Rules

  * All times follow **Sri Lanka Standard Time (SLST)**.
  * All submissions must be original work that has not been previously published.
  * Deadlines are final; missing a deadline results in **zero marks for that specific phase**, though teams can still continue to the next phase.
  * Transparent disclosure of all AI tools used is mandatory across all three phases.
